# 三空间与旅行架构

本专题是三空间的需求与接口权威来源。2026-11-13 用户授权提交、推送和发布当前成果；未授权内容迁移，后续修改的发布授权另行确认。发布结果见 [NOW](context/NOW.md)。

## 用户确认

- 启动开场后进入中间远坂凛主页，左为艾蕾，右为弓凛旅行入口。简体中文，兼顾桌面和手机。
- 开场（2026-11-06 收窄）：桌面与手机均覆盖整个视口，在暖白留白上逐笔写 Rinna，最后补上的 i 点为空心圆；参考 [Marriott Bonvoy 启动录屏](https://60fps.design/shots/marriott-bonvoy-splash) 的圆环处理，由该圆直接放大揭开主页。用户允许先试自然粗细的钢笔笔触，观感待验收；宝石及后续演出暂缓。当前试作约 3.3 秒，可跳过、可重播；返回主页不强制重复。
- 凛主页采用伸手施放宝石魔术的构图，远景宅邸、中景角色、近景魔术与轻微视差，保留欢迎语、少量近况和左右入口。
- 艾蕾包含原版与水艾蕾三个阶段，共四态。原型配色不代表准确游戏设定。
- 弓凛采用侧向角色托起地球的构图；松手、地球向前、镜头靠近、云散后，在到访国家出现不同服装的藤田琴音努努。支持旋转与远景聚合，预留媒体/3D 和失败降级。
- 旅行层级：弓凛入口 → 地球 → 国家 → 骑凛摩托及当地地标过场 → 国家收藏 → 具体旅程。支持中国国内与日本以外海外旅行，不编造到访记录。
- 国家收藏保留墨绿护照、连续纸页、贴签、翻页、地图和正文；手机保留双页。照片与文字优先。骑凛过场取代光点盖章主过场，可跳过，阅读返回不重复强制演出。
- 顶部下拉控制中心含导航、时间、动效、重播开场和继续阅读，预留小组件；不恢复音乐或接入新服务。
- 底部上拉彩蛋为安和昴依次露发梢、眼睛、探头，带出页脚；正式动作资产后补。
- 动效统一服从用户开关与系统减少动态。手机使用可见把手和点击替代，不接管系统边缘手势或正文纵向滚动。

## 设计建议与待确认

四枚灵基星印直接切换四态，联动角色/场景/光效但不改变内容和阅读位置，是当前实现建议；切换方式可后续调整。日常收藏室的简介、最近喜欢、作品与娃衣/收藏尚未最终确定，当前仅显示待整理状态。

国内采用国家 → 城市/地区 → 旅程，海外采用国家 → 旅程；按实际数据保守适配。当前不迁移后端数据库，不把示例国家或原型旅程作为真实记录。

## 第一阶段接口

- `/`、`/eresh`、`/archer` 为三个独立空间；`/travel` 为地球；`/travel/:country` 为国家收藏；`/travel/:country/trips/:tripId` 可直接打开既有旅程。`/passport` 兼容入口转至日本收藏；原 `/blog/:slug` 继续有效。
- `features/experience/` 管理外壳、角色场景描述、开场/国家过场和会话状态；只挂载当前页面，不保留后台场景动画。动效控制复用共享偏好。
- 场景资产描述预留背景、人物、前景，当前使用明确标注的构图占位；`SceneStage` 的分层插槽可接后续媒体与交互。
- `features/travel/domain/countries.js` 负责国家目录、坐标、努努服装/地标接口和分组。旧 `/api/passport` 当前属于日本数据源，缺少国家字段时只由该数据源适配为日本；明确的国家字段优先，未知国家不归入日本。服务兼容可选 `Country`、`Region`、`City` 文本字段，输出 `country`、`region`、`city`；国家值使用目录 id（如 `cn`、`jp`、`fr`），也兼容已列出的中文/英文名称；本轮未创建字段或修改远端内容。新增国家只需补充目录和真实记录，不需要改护照模板。
- 旅行父布局共享摘要/详情缓存；国家页面复用既有护照及弹窗。中国使用 `region` / `city` 分组，无该字段时保留“地区待整理”。地图只在国家有适配器时启用，避免将日本地图用于其他国家。
- `TravelGlobe` 接受 `visited` 和 `select` 事件；未来 `renderer` 插槽接收国家、旋转角度、远景状态及 `select` / `fail` 回调。渲染异常或主动报告失败后卸载媒体并回退投影；国家列表独立可用。媒体实现负责在卸载时释放 GPU、监听器和帧循环。
- 过场控制器支持替换、跳过、取消与销毁；路由改变、页面隐藏会取消待导航过场；动效关闭会立即完成当前过场。继续阅读仅在会话中存储本站合法旅行地址，关闭旅程不覆盖该地址；目前恢复到最后打开的旅程入口，不承诺恢复到正文某一段。关闭会话后可重新播放开场；存储不可用时仍能操作。

## 验收范围

第一阶段交付可运行结构和简洁占位界面。最终立绘、宅邸、准确四态、努努服装、骑凛摩托、地标影片及 3D 球体属于后续逐页美术；当前地球是可旋转的二维投影降级实现，不冒充最终 3D。

早期使用逻辑/生命周期回归与构建验证；后续浏览器证据见 [NOW](context/NOW.md)。2026-11-06 起每次页面改动必须自行打开本地预览检查，旅行功能亦适用；真实手机手感及最终美术另行由用户验收。
