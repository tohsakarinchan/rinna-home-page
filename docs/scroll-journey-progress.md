# 滚动游记与照片管理

2026-10-12：桌面弹窗内向下滚过地图后转为正文在左、地图在右；向上回到地图恢复单栏。复用同一个 Leaflet 实例，保留阅读锚点，段落关联地点并显示已走过的示意线，手动地图交互暂停跟随。窄屏保持单栏。

正文按实际地名匹配 Notion 站点；未知段落不按比例猜测地点。后续可用显式 stopIds 对应重访。照片由站点的 Photo、Photo alt、Photo credit、Photo source 管理，正文读取对应站点照片；原始备份目录不作为网站路径。

已从用户本地备份 2024-06-07 的 26 张照片中选出 8 张，以最长边 1600px 的 JPEG 副本上传 Notion。未改变原图，网页副本不带原始 EXIF。分别为进城车窗（101000）、坡道（122507）、国立竞技场（141730）、御苑（150610）、明治神宫（154807）、三轩茶屋站牌（173107）、下北泽站周边（180540）、寿司晚餐（194807）。照片时间用于筛选，不作为地理定位证据。保留坡道与分店的不确定性。千登世步道桥尚未配图。

可持续维护：本地保管原图 → 挑选网页副本 → 上传 Notion Stops 的 Photo → 填写说明、来源与日期。网站 API 每次返回新的有效照片链接，不将短期签名 URL 写死在源码。文章与地点数据继续以 Notion 为准。

验证：11 项测试通过；前端 Vite 与服务端打包通过。按既有用户要求，未操作浏览器验证，视觉和滚动效果由用户查看。临时选图联系表与上传辅助文件在被 Git 忽略的 photo-review 目录。
